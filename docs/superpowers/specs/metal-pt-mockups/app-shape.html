Metal-PT: how should the app be shaped?

Both options have the same pieces — global hotkey (⌃⇧F6) to start/stop recording, an in-game overlay, run summaries, comparisons and Submit. The question is where you spend your time between games.

A

Menu-bar first

Lives in the menu bar. The dropdown shows live stats and Record. Runs, Compare and Monitor open as separate small windows when you need them. No Dock icon.

B

One main window + menu bar

A normal app window with a sidebar (Live · Runs · Compare · Submit · Settings), plus a small menu-bar item for status and Record. Dock icon while the window is open.
